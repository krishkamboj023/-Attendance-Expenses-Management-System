Attendance and Expenses Management System

Project Description

The Attendance and Expenses Management System is a Python-based, menu-driven application designed to manage student attendance, expenses, student grades, and billing records.

It provides different management options through a simple command-line interface.

Features

1. Expense Management

Add new expenses.

View all expenses.

Calculate total expenses.

Organize expenses by category.

2. Attendance Management

Add student attendance records.

Calculate attendance percentage.

Check attendance eligibility.

Display attendance records.

3. Student Grading System

Enter student marks.

Calculate total and average marks.

Assign grades.

Display pass or fail results.

4. Billing System

Create customer bills.

Calculate item-wise amounts.

Apply discounts.

Calculate 18% tax.

Display final bill amounts.

5. Reports

Display total expenses.

Count attendance records.

Count student records.

Count bills created.

Calculate class average.

How to Run the Project

Download or clone this repository.

Open the project folder in VS Code.

Open the terminal.

Run the following command:

python project.py

Select an option from the main menu.
